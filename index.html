chess.com account

Games are downloaded from the public chess.com API and stored in this browser. Finished months are never downloaded again; only new games are fetched and analysed when you sync.

Engine analysis

Stockfish 16.1 (with its neural-network evaluation) runs in your browser and checks the moves you play most often in the opening (depth 16; live analysis in Openings deepens to depth 24). Results are cached, so each position is analysed only once.

About

Pieces: cburnett set by Colin M.L. Burnett (GPLv2+). Engine: Stockfish 16.1 via Stockfish.js (GPLv3). Opening notes are hand-written for this repertoire.
